## 소개
휴머노이드 로봇의 기구 설계와 제어 기술을 함께 다룰 수 있는 로봇 개발자를 목표로 성장해 왔습니다.  
데이터사이언스와 인공지능을 기반으로 문제를 분석하고, 실제 로봇 제작과 설계를 통해 이를 구현하는 데 강점을 가지고 있습니다.  
앞으로는 로봇 스포츠와 산업 현장에서 활용 가능한 지능형 로봇 시스템을 개발하는 엔지니어가 되고자 합니다.

## 교육

### 광운대학교 정보융합학부 주전공
- 주요 분야: 데이터사이언스, 인공지능
- 데이터 기반 문제 해결과 인공지능 응용 기술을 학습함
- 로봇 제어와 연계할 수 있는 소프트웨어적 사고 역량을 쌓음

### 광운대학교 로봇학부 복수전공 (가상)
- 주요 분야: 로봇 설계
- 휴머노이드 로봇의 구조 설계와 기구 메커니즘을 중점적으로 학습함
- 실제 제작 중심의 프로젝트를 통해 설계 역량을 발전시킴

## 인턴 경력

### 2029 ~ 현재: 로보티즈 액추에이터 설계부문 인턴 수행 (가상)
- 로봇용 액추에이터 구조 설계 보조
- 관절 구동부의 성능 개선을 위한 테스트 및 분석 참여
- 실제 로봇 구동 환경을 고려한 설계 검토 경험 축적
